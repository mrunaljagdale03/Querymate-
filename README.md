# QueryMate – Student Assistance Chatbot

## 📌 Description
QueryMate is an AI-based chatbot that helps students get instant answers to college-related queries like fees, scholarships, and placements.

## 🚀 Features
- Query resolution
- Personalized recommendations
- FAQ system
- Student-friendly interface

## 🛠️ Technologies Used
- HTML
- CSS
- JavaScript
- Basic NLP concepts
